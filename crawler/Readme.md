# ChromeDriver
Precisa instalar o chromedriver
	1. Atualize seu crome
	2. acesse o https://chromedriver.chromium.org/downloads
	3. acesse o https://googlechromelabs.github.io/chrome-for-testing/
	4. baixe a versão compativel com seu chrome
	5. configure o arquivo appsettings.json com os caminhos do DriverPath e do ChromePath
	6 configure o AddArgument no arquivo appsettings.json com o caminho da sua sessão no chrome por exemplo C:\\Users\\wdossantos\\AppData\\Local\\Google\\Chrome\\User Data\\ se não existir essas pastas depois do appData, basta criar
